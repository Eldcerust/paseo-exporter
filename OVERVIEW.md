Export a Paseo conversation as formatted Markdown or structured JSON, archive it using your saved export settings, and import the saved file back into a new chat with its conversation loaded as context. Export and Archive are actions inside the same Export popup or panel. The Export tool can move into the Pill hub. `/export`, `/archive`, and the Command Center open the same exporter.

Archived chats appears in the main sidebar alongside History, Search, and Schedules. Its default Saved export files view lists conversation exports from your host folder, current custom default folders, and a durable catalog of files saved by this version. You can scan another folder or inspect a file by its absolute host path. Select a file, review the provider/model and an existing working directory, then choose Restore from file. The source file remains unchanged and the original Paseo chat does not need to exist.

Restore from file is context import, not reconstruction of native message history. It creates a new chat with the complete export embedded in its additional system context. No initial prompt is submitted and old commands are not replayed. Send your next message to continue. Original message bubbles, provider state, binary attachments, and omitted export content are not recreated. Paseo's provider-import endpoint resumes an existing provider session by ID and does not accept arbitrary transcript messages. Imports over 1 MiB fail before chat creation rather than being truncated; provider context and launch limits also apply. The secondary Paseo native archives view separately offers Unarchive for existing native sessions.

Choose Markdown or JSON, whether to include reasoning, tools, and timestamps, and a destination: the current device's clipboard, `~/Paseo Exports` on the connected host, a session-folder `Paseo Exports` directory, or a custom absolute host folder. Save workspace or host defaults; workspace choices take precedence. Archive requires a saved folder destination and an inactive chat. It saves the file and catalog receipt before hiding the original. A failed save or catalog registration leaves the chat active. After the chat is archived, Archive also archives the chat's own workspace so the session leaves the sidebar, closing that workspace's terminals. The workspace is kept, with the reason shown, when another chat is still active in it or when it is a Git worktree, so no other chat is archived and no worktree folder is deleted. Unarchiving a chat does not restore an archived workspace; Paseo offers Restore for it when you open the chat. Paseo can also archive managed child chats, whose histories are separate.

Requires Paseo 0.15.3 or a compatible later release on both the daemon and app, with an available agent provider for imported chats. Preview and inspection send file content over the existing Paseo connection. Context import places the conversation in the new agent configuration, and using that chat can send it to the selected provider. Path-only catalog receipts are stored under `~/Paseo Exports/.archive-catalog`, separated by host identity. Saved defaults, receipts, and files survive plugin reloads. Old session-folder exports may require a folder scan. Content removed by provider retention or compaction and attachment binaries are not recovered.
